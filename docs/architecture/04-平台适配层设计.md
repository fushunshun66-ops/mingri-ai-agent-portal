### 2.2 插件化设计原则

| 原则 | 说明 |
|---|---|
| **开闭原则** | 对扩展开放，对修改关闭。新增平台只需添加新模块 |
| **接口隔离** | 适配器接口精炼，只暴露必要方法 |
| **依赖倒置** | chat 服务依赖 BaseAdapter 抽象，不依赖具体适配器 |
| **热插拔** | 适配器可独立打包，注册表支持动态发现 |

### 2.3 适配器生命周期

```
注册 (register)
  │ 实现 BaseAdapter 接口，在 adapter_registry 中注册
  ▼
初始化 (initialize)
  │ 加载 platform_connection 配置，初始化 API 客户端
  ▼
就绪 (ready)
  │ 通过健康检查
  ▼
运行 (running)
  │ 接收 chat 服务调用，代理到外部平台
  ▼
停用 (disabled)
  │ 连接失效或管理员主动停用
```

## 3. 适配器基类接口定义

### 3.1 BaseAdapter（Python 抽象基类）

```python
from abc import ABC, abstractmethod
from typing import AsyncIterator, Optional
from dataclasses import dataclass, field
from datetime import datetime


# ── 核心数据结构 ──

@dataclass
class AdapterContext:
    """适配器上下文，包含连接信息和调用参数"""
    connection_id: str
    tenant_id: str
    platform_config: dict          # agent.platform_config
    connection_config: dict        # platform_connection.config (含解密后的 api_key)


@dataclass
class ChatRequest:
    """统一对话请求"""
    query: str                     # 用户消息
    session_id: str                # 对话会话 ID（用于多轮上下文）
    conversation_id: Optional[str] = None  # 平台侧会话 ID（首次对话后由平台返回）
    files: list[dict] = field(default_factory=list)  # [{url, type, name}]
    user_id: str = ""
    extra: dict = field(default_factory=dict)  # 平台特定扩展参数


@dataclass
class ChatResponse:
    """对话响应（非流式全量返回）"""
    content: str
    conversation_id: Optional[str] = None
    metadata: dict = field(default_factory=dict)
    # metadata 示例：
    # {
    #     "tokens": {"prompt": 100, "completion": 200},
    #     "model": "gpt-4",
    #     "finish_reason": "stop",
    #     "platform_raw": {...}   # 平台原始响应（调试用）
    # }


@dataclass
class StreamChunk:
    """流式响应块"""
    content: str                   # 本次增量文本
    done: bool = False             # 是否结束
    conversation_id: Optional[str] = None
    metadata: dict = field(default_factory=dict)


@dataclass
class AgentInfo:
    """平台上的 Agent 信息（用于同步）"""
    platform_agent_id: str         # 平台侧 Agent ID
    name: str
    description: str = ""
    icon_url: str = ""
    type: str = "chat"             # chat / workflow / completion
    extra: dict = field(default_factory=dict)


# ── 基础适配器抽象 ──

class BaseAdapter(ABC):
    """平台适配器抽象基类"""

    # 适配器元信息（由子类设置）
    platform_type: str = ""        # dify / n8n / coze
    platform_name: str = ""        # 显示名称
    platform_version: str = "1.0"

    def __init__(self, context: AdapterContext):
        self.context = context
        self._client = None        # HTTP 客户端（子类初始化）

    # ── 核心方法 ──

    @abstractmethod
    async def chat(self, request: ChatRequest) -> ChatResponse:
        """非流式对话：发送消息，返回完整响应"""
        ...

    @abstractmethod
    async def chat_stream(self, request: ChatRequest) -> AsyncIterator[StreamChunk]:
        """流式对话：发送消息，逐块返回响应"""
        ...

    @abstractmethod
    async def get_info(self, platform_agent_id: str) -> AgentInfo:
        """从平台获取 Agent 的详细信息"""
        ...

    @abstractmethod
    async def list_agents(self) -> list[AgentInfo]:
        """列出此连接下平台上的所有 Agent"""
        ...

    @abstractmethod
    async def health_check(self) -> bool:
        """检测连接是否可用"""
        ...

    # ── 可选方法（可重写） ──

    async def get_conversations(self, platform_agent_id: str) -> list[dict]:
        """获取平台上的历史会话列表（可选）"""
        raise NotImplementedError

    async def get_messages(
        self, platform_agent_id: str, conversation_id: str
    ) -> list[dict]:
        """获取平台上某次会话的消息历史（可选）"""
        raise NotImplementedError

    async def stop_generation(self, task_id: str) -> bool:
        """停止正在生成的响应（可选）"""
        raise NotImplementedError

    async def feedback(
        self, message_id: str, rating: str, content: str = ""
    ) -> bool:
        """提交对话反馈（可选）"""
        raise NotImplementedError
```

### 3.2 适配器注册表

```python
from typing import Type, Dict, Optional


class AdapterRegistry:
    """适配器注册表 — 管理所有平台适配器的注册与发现"""

    _adapters: Dict[str, Type[BaseAdapter]] = {}

    @classmethod
    def register(cls, adapter_cls: Type[BaseAdapter]):
        """注册一个适配器类"""
        if not adapter_cls.platform_type:
            raise ValueError(f"适配器 {adapter_cls.__name__} 缺少 platform_type")
        cls._adapters[adapter_cls.platform_type] = adapter_cls

    @classmethod
    def get(cls, platform_type: str) -> Optional[Type[BaseAdapter]]:
        """根据平台类型获取适配器类"""
        return cls._adapters.get(platform_type)

    @classmethod
    def list_platforms(cls) -> list[dict]:
        """列出所有已注册的平台"""
        return [
            {
                "platform_type": cls_.platform_type,
                "platform_name": cls_.platform_name,
                "platform_version": cls_.platform_version,
            }
            for cls_ in cls._adapters.values()
        ]

    @classmethod
    def create(
        cls, platform_type: str, context: AdapterContext
    ) -> BaseAdapter:
        """创建适配器实例"""
        adapter_cls = cls.get(platform_type)
        if not adapter_cls:
            raise ValueError(f"未找到平台适配器: {platform_type}")
        return adapter_cls(context)
```

## 4. 三平台 API 差异分析

### 4.1 Dify

| 维度 | Dify |
|---|---|
| **概述** | 开源 LLM 应用开发平台，提供 Chat/Completion/Workflow 三种应用模式 |
| **认证方式** | API Key（Bearer Token，分应用级 API Key） |
| **对话 API** | `POST /v1/chat-messages`，支持 SSE 流式 |
| **流式格式** | SSE，每行 `data: {...}`，`event: message` / `event: message_end` |
| **多轮对话** | 通过 `conversation_id` 关联 |
| **文件上传** | 先调用 `POST /v1/files/upload` 获取 `upload_file_id` |
| **Agent 列表** | `GET /v1/apps`（需应用级 API） 或 `GET /console/api/apps`（需管理 API） |
| **停止生成** | `POST /v1/chat-messages/{task_id}/stop` |
| **反馈** | `POST /v1/messages/{message_id}/feedbacks` |
| **请求示例** | 见下方 |

```json
// Dify Chat 请求
POST /v1/chat-messages
Headers: Authorization: Bearer {api_key}
Body: {
  "query": "你好",
  "user": "user-123",
  "conversation_id": "",
  "inputs": {},
  "files": [{"type": "image", "transfer_method": "remote_url", "url": "..."}],
  "response_mode": "streaming"
}

// Dify SSE 响应示例
data: {"event": "message", "task_id": "...", "message_id": "...", "answer": "你", "created_at": 123}
data: {"event": "message", "task_id": "...", "message_id": "...", "answer": "好", "created_at": 123}
data: {"event": "message_end", "conversation_id": "...", "metadata": {"usage": {...}}}
```

### 4.2 N8N

| 维度 | N8N |
|---|---|
| **概述** | 开源工作流自动化平台，可通过 Webhook 触发，返回 JSON |
| **认证方式** | API Key（`X-N8N-API-KEY` Header）或 Webhook 自带鉴权（Header Auth / 无鉴权） |
| **对话 API** | 无原生对话 API，通过 Webhook 触发工作流（同步或异步） |
| **流式格式** | ⚠️ 原生不支持 SSE 流式。需通过轮询或 WebSocket 模拟 |
| **多轮对话** | 需在门户层维护上下文，每次请求带上历史消息 |
| **文件上传** | 通过 Webhook binary data 或先在门户层上传后传 URL |
| **Agent 列表** | `GET /api/v1/workflows` |
| **工作流结果** | 同步 Webhook 直接返回 JSON；异步 Webhook 需轮询 `GET /api/v1/executions/{id}` |
| **请求示例** | 见下方 |

```json
// N8N Webhook 请求
POST /webhook/{webhook_path}
Headers: Content-Type: application/json
Body: {
  "query": "请分析这份数据",
  "session_id": "portal-session-uuid",
  "history": [
    {"role": "user", "content": "上一轮消息"},
    {"role": "assistant", "content": "上一轮回复"}
  ],
  "files": [{"url": "..."}]
}

// N8N 工作流期望返回格式（约定）
{
  "output": "这是 AI 的回复内容",
  "metadata": {"tokens": 150}
}
```

**N8N 适配难点**：
1. **无原生流式**：需实现"伪流式"——等完整响应后逐字输出（前端体验不真实），或通过 N8N WebSocket 节点推送（复杂度高）
2. **上下文管理**：门户层需维护对话历史，每次请求完整发送
3. **响应格式不统一**：不同工作流输出 JSON 结构不同，需约定 `output_path` 字段提取响应文本

### 4.3 Coze（扣子）

| 维度 | Coze |
|---|---|
| **概述** | 字节跳动 AI Bot 开发平台，提供对话 Bot、知识库、插件 |
| **认证方式** | Personal Access Token（`Authorization: Bearer {token}`） |
| **对话 API** | `POST /v3/chat`，支持 SSE 流式 |
| **流式格式** | SSE，事件类型：`conversation.chat.created` / `conversation.chat.in_progress` / `conversation.message.delta` / `conversation.chat.completed` |
| **多轮对话** | 通过 `conversation_id` 关联 |
| **文件上传** | `POST /v1/files/upload` |
| **Bot 列表** | `GET /v1/space/list_bot`（获取空间下所有 Bot） |
| **停止生成** | `POST /v3/chat/cancel` |
| **请求示例** | 见下方 |

```json
// Coze Chat 请求
POST /v3/chat
Headers: Authorization: Bearer {access_token}
Body: {
  "bot_id": "bot-id",
  "user_id": "portal-user-id",
  "stream": true,
  "auto_save_history": true,
  "additional_messages": [
    {"role": "user", "content": "你好", "content_type": "text"}
  ]
}

// Coze SSE 响应示例
event: conversation.message.delta
data: {"content": "你好！"}

event: conversation.chat.completed
data: {"usage": {"token_count": 50}}
```

## 5. 差异对比总结表

| 维度 | Dify | N8N | Coze |
|---|---|---|---|
| **Agent 概念** | App（应用） | Workflow（工作流） | Bot（机器人） |
| **对话模式** | Chat / Completion / Workflow | Webhook（同步/异步） | Chat |
| **流式输出** | ✅ SSE | ❌ 不支持 | ✅ SSE |
| **多轮对话** | ✅ conversation_id | ❌ 需门户管理 | ✅ conversation_id |
| **文件上传** | ✅ 独立 API | ⚠️ 约定方式 | ✅ 独立 API |
| **Agent 列表获取** | `GET /v1/apps` | `GET /api/v1/workflows` | `GET /v1/space/list_bot` |
| **停止生成** | ✅ `/stop` | ❌ 不支持 | ✅ `/cancel` |
| **用户反馈** | ✅ `/feedbacks` | ❌ 不支持 | ❌ 不支持 |
| **认证方式** | App API Key | API Key / 无鉴权 | PAT (Personal Access Token) |
| **上下文管理** | 平台侧 | 门户侧 | 平台侧 |

## 6. 适配器实现示例：Dify 适配器

```python
class DifyAdapter(BaseAdapter):
    """Dify 平台适配器"""

    platform_type = "dify"
    platform_name = "Dify"

    def __init__(self, context: AdapterContext):
        super().__init__(context)
        base_url = context.connection_config["base_url"]
        api_key = context.connection_config["api_key_encrypted"]  # 已解密
        self._client = httpx.AsyncClient(
            base_url=base_url,
            headers={"Authorization": f"Bearer {api_key}"},
            timeout=context.connection_config.get("timeout", 30),
        )

    async def chat(self, request: ChatRequest) -> ChatResponse:
        """非流式对话"""
        resp = await self._client.post("/v1/chat-messages", json={
            "query": request.query,
            "user": request.user_id,
            "conversation_id": request.conversation_id or "",
            "inputs": request.extra.get("inputs", {}),
            "files": self._format_files(request.files),
            "response_mode": "blocking",
        })
        resp.raise_for_status()
        data = resp.json()
        return ChatResponse(
            content=data["answer"],
            conversation_id=data.get("conversation_id"),
            metadata={
                "tokens": {
                    "prompt": data["metadata"]["usage"].get("prompt_tokens", 0),
                    "completion": data["metadata"]["usage"].get("completion_tokens", 0),
                },
                "message_id": data["message_id"],
                "platform_raw": data,
            },
        )

    async def chat_stream(self, request: ChatRequest) -> AsyncIterator[StreamChunk]:
        """流式对话（SSE 解析）"""
        async with self._client.stream("POST", "/v1/chat-messages", json={
            "query": request.query,
            "user": request.user_id,
            "conversation_id": request.conversation_id or "",
            "inputs": request.extra.get("inputs", {}),
            "files": self._format_files(request.files),
            "response_mode": "streaming",
        }) as resp:
            resp.raise_for_status()
            async for line in resp.aiter_lines():
                if line.startswith("data: "):
                    data = json.loads(line[6:])
                    event = data.get("event")

                    if event == "message":
                        yield StreamChunk(
                            content=data.get("answer", ""),
                            done=False,
                        )
                    elif event == "message_end":
                        yield StreamChunk(
                            content="",
                            done=True,
                            conversation_id=data.get("conversation_id"),
                            metadata={"tokens": data.get("metadata", {}).get("usage", {})},
                        )

    async def get_info(self, platform_agent_id: str) -> AgentInfo:
        """从 Dify 获取应用信息"""
        resp = await self._client.get(f"/console/api/apps/{platform_agent_id}")
        resp.raise_for_status()
        data = resp.json()
        return AgentInfo(
            platform_agent_id=platform_agent_id,
            name=data["name"],
            description=data.get("description", ""),
            icon_url=data.get("icon", ""),
            type=data.get("mode", "chat"),
            extra=data,
        )

    async def list_agents(self) -> list[AgentInfo]:
        """列出 Dify 平台上的所有应用"""
        resp = await self._client.get("/console/api/apps", params={"page": 1, "limit": 100})
        resp.raise_for_status()
        data = resp.json()
        return [
            AgentInfo(
                platform_agent_id=app["id"],
                name=app["name"],
                description=app.get("description", ""),
                icon_url=app.get("icon", ""),
                type=app.get("mode", "chat"),
                extra=app,
            )
            for app in data.get("data", [])
        ]

    async def health_check(self) -> bool:
        """检测连接是否可用"""
        try:
            resp = await self._client.get("/v1/apps")
            return resp.status_code == 200
        except Exception:
            return False

    def _format_files(self, files: list[dict]) -> list[dict]:
        """将统一文件格式转换为 Dify 格式"""
        return [
            {
                "type": f.get("type", "image"),
                "transfer_method": "remote_url",
                "url": f["url"],
            }
            for f in files
        ]
```

## 7. 新增平台的接入流程

当需要接入新平台（如 LangChain、百炼等）时，只需以下 4 步：

### Step 1：创建适配器目录
```
adapters/adapters/new_platform/
├── __init__.py
├── adapter.py      # 继承 BaseAdapter
├── client.py       # 封装 NewPlatform HTTP API
└── models.py       # 平台特有数据模型映射
```

### Step 2：实现 BaseAdapter 的 5 个抽象方法
- `chat()` / `chat_stream()` — 核心对话能力
- `get_info()` — 获取单个 Agent 信息
- `list_agents()` — 列出平台 Agent 列表
- `health_check()` — 连接健康检测

### Step 3：在 registry 中注册
```python
# adapters/adapters/new_platform/__init__.py
from .adapter import NewPlatformAdapter
from adapters.core.adapter_registry import AdapterRegistry

AdapterRegistry.register(NewPlatformAdapter)
```

### Step 4：注册 API 端点
新增平台类型会自动出现在 `GET /api/adapters/platform-types` 响应中，管理员即可在前端创建对应连接。

**不需要修改任何其他代码**。

## 8. 错误处理与降级策略

### 8.1 统一错误码

| 适配器错误 | HTTP 状态 | 说明 |
|---|---|---|
| `ADAPTER_NOT_FOUND` | 404 | 平台类型不支持 |
| `CONNECTION_FAILED` | 502 | 无法连接到外部平台 |
| `CONNECTION_TIMEOUT` | 504 | 外部平台响应超时 |
| `AUTHENTICATION_FAILED` | 502 | 外部平台认证失败（API Key 过期等） |
| `PLATFORM_ERROR` | 502 | 外部平台返回的业务错误 |
| `UNSUPPORTED_OPERATION` | 501 | 该平台不支持请求的操作 |

### 8.2 降级策略

| 场景 | 降级方案 |
|---|---|
| 平台不可用 | 返回友好错误提示，记录连接状态为 `error` |
| 流式不可用（如 N8N） | 降级为非流式，完整响应后一次性返回 |
| 多轮上下文本平台不支持 | 门户层维护上下文，每次请求时注入 |
| 文件上传不支持 | 门户层上传到 MinIO，传 URL 给平台 |
| 历史会话获取失败 | 仅显示门户侧记录的会话 |
